⚙️ Informations générales

🔐 Gestion des données

Les données de cette version sont enregistrées dans le localStorage du navigateur. Cela convient à une démonstration locale. Pour une véritable plateforme en ligne, il faudra utiliser une base de données et une authentification sécurisée.

⚠️ Ne mets jamais un mot de passe administrateur, une clé API ou un secret dans ce fichier HTML/JavaScript côté client.
💡 L'export permet de sauvegarder les données actuellement présentes dans le navigateur.

🛡️ Zone de sécurité

Cette zone est destinée aux opérations sensibles. La suppression des données locales est définitive pour ce navigateur. Effectue une exportation avant toute suppression.

🔒 Pour la version en ligne, utilise une authentification administrateur côté serveur avec des sessions sécurisées ou des tokens protégés.
🛡️ Les informations sensibles doivent rester côté serveur et ne doivent jamais être exposées dans le code public de ton site.
