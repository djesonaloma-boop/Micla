Projet web avec espace public et espace administration.

## Code secret administrateur

`MICLA123@`

## Lancer localement avec Python

```bash
python admin.py
```

Puis ouvrir `http://localhost:8000/`.

## Important

Le code secret dans un site statique JavaScript n'est pas une authentification serveur sécurisée.
Pour une production réelle, connecter l'administration à un backend avec authentification côté serveur.
